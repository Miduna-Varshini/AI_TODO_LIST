# AI Todo List

An intelligent task management application built with Streamlit, Groq AI, and Supabase.

## Features

* Create and manage tasks easily
* Mark tasks as completed
* Delete tasks instantly
* Store tasks in Supabase
* Generate task lists from goals using AI
* Convert AI-generated plans into actionable tasks with one click

## Tech Stack

* Python
* Streamlit
* Groq API
* Supabase

## How It Works

1. Add tasks manually from the Tasks tab.
2. Describe a goal in the AI Generator tab.
3. Let AI create a step-by-step task list.
4. Add generated tasks directly to your todo list.
